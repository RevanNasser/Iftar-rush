# Iftar Rush 🌙

A fun Ramadan-themed catching game where you move a basket to collect iftar food items before time runs out!

## How to Play 🎮

- Move your mouse to control the basket
- Catch as many food items as possible within 30 seconds
- Each food item 🧆 collected adds to your score


## Tech Stack

- React
- TypeScript
- Vite

## Getting Started

### Install dependencies

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```

## Add Your Favorite Iftar Dishes 🍽️

Want to make the game more fun? You can expand the iftar table with your favorite foods : 

1. Add your food SVG images to `public/food/` folder
2. Run the generation script:

```bash
npm run generate-food
```

All your dishes will instantly appear in the game — ready to be caught in Iftar Rush!

Feel free to add traditional dishes from your country and scale the food variety 🌍🥘
